About this tool — coverage, methodology & data sources (click to expand)
Coverage right now: Both SIMA (all ~40 active CBSA Measures in Force cases) and surtax (all 6 currently active surtax-imposing Orders in Council) are cross-checked live against any HS code you search. The origin dropdown lists all 40 actual countries that appear across current SIMA cases (Vietnam, Chinese Taipei, India, etc. — not just China/US), and surtax matching uses each order's real legal scope (US-only, China-only, any-origin, or origin-excluding) rather than a rough guess. One order (SOR/2025-148) is quota-based — a match there means "check current quota," not "confirmed surtax." Base duty rates in your own tracked list below are still placeholders. This tool does not replace CARM or a binding ruling.
Three data sources live in this file:
1. SURTAX_ORDERS — every currently active surtax-imposing Order in Council. Re-check monthly against laws-lois.justice.gc.ca for each SOR number listed, since amendments happen often (rates, exclusions, and TRQ quotas especially). Deliberately excludes remission/exclusion instruments like Schedule 6 of SOR/2025-122 — that's relief FROM surtax, not applicability, and belongs in a separate tool if you want to build one for remission-checking specifically.

2. SIMA_CASES — the complete CBSA Measures in Force list. Re-check monthly against https://www.cbsa-asfc.gc.ca/sima-lmsi/mif-mev/menu-eng.html

3. SAFEGUARD_MEASURES — currently active safeguard surtax orders under Customs Tariff s.55. These tend to be provisional and fast-moving (200-day windows, CITT inquiries) — re-check status more often than SIMA/surtax.

4. TARIFF_DATA — your own working list (client-specific context, base duty rates). Copy an existing object, change the fields, save.

No build step, no server — just edit and reopen the file in a browser. Update lastUpdated, SIMA_SOURCE_DATE, SURTAX_SOURCE_DATE, and SAFEGUARD_SOURCE_DATE each time you do a pass.
